## Бот-«Заметки» (To-Do List)
**Что понадобится:**
- Язык: Python 3.10+
- Библиотека: 
- База данных: SQLite

### Функционал
1. /start — приветствие и краткая инструкция.
2. Добавить заметку — пользователь пишет текст, бот сохраняет.
3. Показать список — бот выводит все заметки пользователя с номерами.
4. Удалить заметку — по номеру или кнопкой
